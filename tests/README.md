# Peon – Testumgebung

Kleine Tests, die die Addons außerhalb von WoW laden. Die WoW-API wird dabei in jedem Test nachgebaut (Stub): Rahmen, Einstellungsmenü, Slash-Befehle, Ereignisse, Tastenbelegungen.

Lua 5.1 (dieselbe Version wie WoW) liegt fertig im Ordner `..\tools`:

- `lua5.1.exe` für Windows (eine Datei, keine Installation nötig)
- `lua5.1-linux` für Linux (z. B. GitHub Actions)

## Ausführen

Die Tests laufen auf den Addons im Repo (`..\addons`). Ein anderer Ordner geht über die Umgebungsvariable `PEON_ADDONS`.

**Unter Windows:** `run_tests.cmd` doppelklicken. Das Skript wechselt nach `addons\`, startet alle `test*.lua` und zeigt am Ende „ALLE TESTDATEIEN OK“ oder „MINDESTENS EIN TEST FEHLGESCHLAGEN“.

Einzelner Test von Hand:

```
cd /d <Repo>\addons
..\tools\lua5.1.exe ..\tests\test_fish.lua
```

**In Git Bash oder unter Linux:**

```
sh tests/run_tests.sh              # alle Tests
sh tests/run_tests.sh test_cp.lua  # einzelner Test
```

Jeder Test endet mit `ALLE TESTS OK` oder bricht mit `FEHLER: …` ab.

`test_fish.lua` liest die Einstellungen aus `PEON_WTF`. `run_tests.sh` und `run_tests.cmd` setzen dafür die feste Kopie `tests\fixtures\wtf` (Beta-Stand von Mirel-Dorna, ab 25.10.2026), damit der Test nicht von den Spieldaten abhängt. Die Tests laufen auf `addons\` im Repo (anderer Ordner über `PEON_ADDONS`). Die Tests für Peon_Feedback liegen seit 31.10.2026 im Archiv (`<Archiv>\Peon_Feedback_0.2.0\tests\`).

Versionen und Titel lesen die Modultests direkt aus der TOC-Datei (`TocMeta`), damit die Ausgabe immer zur echten Version passt. `test.lua` nutzt bewusst erfundene Testmodule mit festen Versionen.

## Hinweise

- Die Stubs sind bewusst einfach. Ein Fehler wie „attempt to index field 'Low' (a function value)“ kommt meist vom Stub, nicht vom Addon – dann den Stub ergänzen.
- Neue Module bekommen einen eigenen `test_<modul>.lua`. Ausgangspunkt ist `..\vorlage\test_beispiel.lua` (Kern laden, `ADDON_LOADED` feuern, Modul laden, `PLAYER_LOGIN` feuern, prüfen).
